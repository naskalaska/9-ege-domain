# EGE 9 Trainer

Учебный тренажер на Python standard library: HTTP-сервер, обычный HTML/CSS/JS и SQLite.

## Локальный запуск

1. Установите Python 3.13.
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Запустите приложение:

```bash
python app/server.py 127.0.0.1 8088
```

4. Откройте `http://127.0.0.1:8088`.

## Docker Compose

1. Создайте `.env` на основе `.env.example` и обязательно замените `ADMIN_PASSWORD` и `SECRET_KEY`.
2. Соберите и запустите контейнер:

```bash
docker compose up -d --build
```

3. Откройте `http://IP_СЕРВЕРА:8088`.
4. Посмотреть логи:

```bash
docker compose logs -f app
```

5. Остановить:

```bash
docker compose down
```

Данные SQLite хранятся в Docker volume `ege9_data` по пути `/app/data/ege_app.db` внутри контейнера. Volume сохраняется после перезапуска контейнера, пересборки образа и перезапуска VPS.

## Portainer

1. Откройте Portainer.
2. Перейдите в `Stacks`.
3. Нажмите `Add stack`.
4. Вставьте `docker-compose.yml` или подключите репозиторий.
5. Укажите переменные окружения из `.env.example`.
6. Нажмите `Deploy the stack`.
7. Проверьте, что контейнер `ege9-trainer` запущен.
8. Откройте приложение по `http://IP_СЕРВЕРА:8088`.

## Проверка сохранения данных

1. Создайте тестового учителя.
2. Скопируйте его `teacher_code`.
3. Создайте тестового ученика с этим `teacher_code`.
4. Решите несколько заданий.
5. Перезапустите контейнер в Portainer или командой `docker compose restart app`.
6. Войдите снова и проверьте, что пользователь и прогресс сохранились.

## Домен и SSL

Домен не прописывается в коде приложения. Настройка делается снаружи:

1. A-запись домена указывает на IP VPS.
2. Nginx или прокси направляет запросы на контейнер `http://127.0.0.1:8088`.
3. SSL выпускается бесплатно через Let's Encrypt.

Платный SSL не нужен.

## Авторизация и роли

В приложении есть роли `student`, `teacher`, `admin`.

Ученик входит по логину и паролю. `teacher_code` нужен только при регистрации или повторной привязке к учителю.

Учитель входит по логину и паролю, имеет свой `teacher_code` и видит только учеников, у которых `users.teacher_id` равен его `user_id`.

Админ входит по логину и паролю и получает доступ к существующим административным функциям.

Пароли хранятся в таблице `users` в полях `password_salt` и `password_hash`. Новые пароли хешируются через PBKDF2-SHA256. Старые SHA-256-хеши поддерживаются для входа и автоматически обновляются после успешной авторизации.
