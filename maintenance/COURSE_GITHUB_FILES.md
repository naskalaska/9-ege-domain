# Курс: загрузка в GitHub после уменьшения файлов

25 ноября 2026 года.

Причина отказа: «Эксперименты — 8 задач визуала.html» содержал 223 841 829 байт встроенных картинок. GitHub запрещает обычные Git-файлы больше 100 МиБ; при загрузке через браузер предел одного файла составляет 25 МиБ. [Документация GitHub](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github).

Картинки извлечены без перекодирования и потери качества. Одинаковые картинки сохранены в одном экземпляре. Проверены все 124 вхождения; максимальный отдельный ресурс — 8,48 МиБ. HTML «Эксперименты» уменьшился до 124 053 байт, второго урока — до 87 499 байт. Локальные MP4 курса исключены из Git/Docker: текущие страницы используют VK.

Загрузить вместе:

- Обновлённые HTML в `app/Нейровизуал для учителя` — все 13 файлов.
- Всю папку `app/course-media`: 91 извлечённый ресурс и 5 авторских инфографик.
- Обновлённый `app/courses.py` — он умеет выдавать упакованные картинки через защищённый адрес.
- Остальные изменённые файлы приложения, `.gitignore`, `.dockerignore` — как обычно при обновлении проекта.

Резервные исходники в `tmp/course-before-image-extraction` не загружать. Рабочие данные и кэш из `data` также не являются исходниками курса. Папка `app/course-media` нужна на сервере; удалять её после отправки в GitHub нельзя.

В текущем рабочем каталоге нет действующей истории Git: `git status` возвращает `not a git repository`. Поэтому локальные коммиты и удалённый репозиторий этим изменением не переписывались.

Если при push GitHub продолжает указывать старый размер, исходный большой файл уже находится в отправляемом коммите/истории другого checkout. Одного нового коммита с маленькой версией тогда недостаточно: нужно исправить именно неотправленный коммит. Для такого исправления нужен путь к рабочему репозиторию и текст ошибки; автоматически удалять историю или выполнять force push здесь не требуется.

Проверка после изменения: 19 тестов курса прошли; карта, первый и второй урок, «Эксперименты» и цветовой компас проверены в браузере с новой базой и пустым кэшем. Ошибок загрузки картинок не обнаружено.
