## Возможные изменения

1. **Сжатие изображений без потери пикселей.** Проверена выборка из 27 PNG из разных игр и магазина: 52.91 → 40.37 МиБ (23.7% экономии). Кодирование WebP lossless, сравнение всех RGBA-пикселей после декодирования. Исходники не заменены. Если средний результат сохранится, резерв составляет около 225 МиБ для внешних PNG; это оценка по выборке, не гарантированный итог. Нужны обновление прямых и динамических ссылок, MIME, проверки загрузки изображений и генератора офлайн-версий. Текст на памятках, размеры и прозрачность следует сохранить.
2. **Убрать из рабочего дерева временный профиль Chrome:** 79.37 МиБ. Дополнительно можно вынести скриншоты и прочие артефакты QA, сохранив отчёты. Весь maintenance/offline-qa уже исключён из Docker и Git: это уменьшит локальную папку, но не серверную поставку.
3. **Объединить точные дубли ресурсов приложения:** 29.44 МиБ, 27 групп. Это байтовые совпадения SHA-256, а не похожие названия. Например, изображения игры «Игра-знакомство» лежат одновременно в корне и assets; у двух игр с бабочками общие картинки; у Пушинок и suffixes-nouns одинаковый фон. Для используемых обеими играми ресурсов нужен общий путь или серверное сопоставление; удалять без исправления ссылок нельзя. Перечень в size-audit.json. Экономия пересекается с эффектом сжатия изображений, её нельзя просто прибавлять к оценке выше.
4. **Вынести встроенные Base64-картинки из HTML сайта в отдельные файлы.** В «Карте причастия» и «Архитектуре слова» встроенные данные занимают примерно 22.2 и 20.9 МиБ соответственно. Часть этого объёма можно убрать за счёт отказа от Base64, затем сжать сами изображения. Для сайта нужны корректные пути и проверки. Для автономных офлайн-HTML встроенные ресурсы сохранить: это требование комплекта. Байтово идентичных внешних копий этих встроенных изображений при проверке не обнаружено.
5. **Отдельная сборка для размещения.** Тестовые сценарии, инструменты обслуживания и документы разработки можно не включать в серверный образ, оставив их в репозитории. Это небольшой резерв по сравнению с изображениями. Общая папка офлайн-комплекта уже исключена из Docker/Git, поэтому при её возвращении серверная поставка не увеличится.

Сокращение музыки через повторное кодирование и уменьшение разрешения картинок не включены в рекомендации без потери качества. Базы учеников, статистику, банки заданий, памятки и ключи ответов уменьшать удалением нельзя. Документы PDF/DOCX могут быть материалами для учителя или покупателя; их не следует удалять только потому, что они не нужны для запуска игрового экрана.

Предпочтительная последовательность: очистить временные артефакты; сделать проверяемую оптимизацию изображений; объединить точные дубли; затем при необходимости переработать встроенные ресурсы HTML сайта. После изменений проверить сайт, магазин, полные версии игр, динамические картинки и сборку автономных HTML.
