# Курс «Нейровизуал в работе учителя»

## Локальное превью перед публикацией

Дважды нажмите **«Запустить превью курса.cmd»** в корне проекта. Он найдёт Python и откроет браузер по адресу `http://localhost:8098/course-preview`. Окно запуска оставьте открытым. Файл **«Превью_курса_Нейровизуал.html»** содержит инструкции и ссылку на просмотр.

В шапке карты и каждого урока есть ссылка «Управление курсом». В админке есть кнопка «Открыть превью участника». Пароль вводить не нужно; превью открывается обычной страницей без рамки просмотра. Повторный запуск CMD автоматически перезапускает старый экземпляр превью этого проекта. При первом запуске все семь занятий открыты; затем настроенные даты и группы сохраняются, чтобы можно было проверить расписание. Правки текстов, ответы и переписка хранятся в отдельной базе `data/course-preview/ege_app.db`. Реальные оплаты и отправка писем заблокированы. Боевые настройки не меняются.

Для запуска из терминала: `python maintenance/serve-course-preview.py --open-browser`. Если порт занят, закройте предыдущее окно превью либо задайте другой: `--port 8099`.

После обновления приложения и перезапуска сервера автоматически добавятся две активные позиции: личная консультация за 2000 ₽ и курс за 5000 ₽. Существующие настройки магазина и платёжной системы сохраняются. Если приём платежей выключен общей настройкой магазина, его нужно включить в существующей админке.

Управление курсом: кнопка **«Управление курсами»** в админке, адрес `/admin/courses`. Страница участника: `/courses/neurovisual`, ссылка **«Мой курс»** в меню сайта.

## Редактирование

- Вкладка **«Уроки»**: выберите занятие из списка. Поля сгруппированы: видео, материалы занятия, описание и доступ, завершение урока. После изменений нажмите «Сохранить урок».
- Для первого урока предусмотрены два независимых места для внешнего видео; для остальных уроков — по одному. В админке первого урока заполняются поля «Видео 1» и «Видео 2»; любое из них можно оставить пустым. Пока ссылка не добавлена, виден светлый блок ожидания. Локальные MP4-записи к урокам не подключаются. В поле вставляется целиком код `<iframe>` из раздела встраивания VK либо полный адрес `video_ext.php` из его `src`. Ссылки вида `/video-…_…?list=…` не преобразуются автоматически: для них показывается инструкция получить код встраивания, прежнее видео не перезаписывается. Из кода сохраняется только проверенный адрес VK. Для закрытой записи нужен полный адрес с ключом доступа.
- **«Материалы занятия»**: нажмите «Добавить ссылку», введите название и адрес в отдельных полях. На странице урока они появляются по одноимённой кнопке в шапке.
- **«Тексты на самой странице урока»**: откройте редактор и найдите фразу через поиск. HTML-разметку редактировать не нужно. Изменения сохраняются в базе, исходные файлы не перезаписываются.
- Вкладка **«Карта и чат»**: текст под заголовком, общий чат, дополнительные ссылки. Пять исходных материалов отображаются рисованными листиками прямо на карте. Добавленные преподавателем ссылки размещаются на дополнительной ветке под картой.
- Вкладка **«Описание и цена»**: название и описание для магазина, обычная цена, цена акции и её окончание. Изменения используют тот же магазин и механизм акций. Настройки также доступны в общей админке магазина.
- Обложка: `app/static/assets/course/neurovisual-cover.png`. Описание и три иллюстрации взяты с указанной автором страницы `https://naskalaska.github.io/neyrovisual/`; цена остаётся 5000 ₽, пока администратор не настроит акцию.
- Из карточки на общей странице услуг обложка убрана. На подробной странице магазина сохранена галерея и добавлены разделы «Регистрация учителя» и «Возврат» с почтой `anastasia@dimitrieva-av.ru`. Эти тексты можно менять во вкладке «Описание и цена».

## Доступ и группы

Первый урок открыт сразу. Уроки 2–7 изначально закрыты до ручного открытия. Для открытия выберите в настройках урока «Открыт» или «По дате» и сохраните. Все даты вводятся и показываются по Москве.

На вкладке **«Группы»** создайте группу, откройте её настройки и задайте отдельный чат и дату открытия каждого урока. «По настройкам урока» наследует общую дату; «В указанную дату» заменяет её только для этой группы. Все даты вводятся по Москве. Пустое поле чата группы использует общий чат курса; заполненное заменяет его на карте, в уроках и ссылках для отправки домашнего задания.

Вверху той же вкладки находится **«В какую группу зачислять новые оплаты»**. Выберите группу и нажмите **«Сохранить группу для новых оплат»**. При подтверждении платежа эта группа закрепляется за заказом. Если покупатель ещё не зарегистрирован, после регистрации с почтой покупки он попадёт в закреплённую группу. Переключение группы для новых оплат не переводит прежних покупателей. Для ручного перевода используется вкладка «Участники».

Количество участников в группе не ограничено. Подпись «Пройдено уроков: N из 7» относится только к прогрессу конкретного участника.

Доступ предоставляется по подтверждённой оплате в существующем магазине, включая покупку курса в корзине с другими товарами. При регистрации выберите роль «Учитель» и ту же почту, что указана при оплате, чтобы отслеживать материалы и прогресс. Покупатель без аккаунта возвращается в курс после регистрации, входа и принятия документов. Оплата не зависит от успешной отправки письма: подтверждённая покупка уже даёт доступ.

## Ответы и обратная связь

Поля и отметки интерактивных материалов, итоговые чек-листы и прохождение сохраняются автоматически; есть также кнопка явного сохранения. Дополнительные материалы размещены на исходной карте курса и открываются полноценными страницами. Ответы в них сохраняются в контексте карты.

Шкала на общей карте показывает выполненные домашние задания из семи. Управление: **«Участники» → раскрыть участника → «Выполнение домашних заданий»**. Администратор ставит или снимает отметку для каждого урока; изменения сохраняются сразу. По этим отметкам заполняется шкала и окрашиваются цветы карты. Самостоятельная отметка участника «Урок пройден» хранится отдельно и не засчитывает домашнее задание. Состояние шкалы обновляется при открытии или обновлении карты.

В каждом уроке одно открытое домашнее задание в крупном голубом блоке, как во втором исходном занятии. Дубли из исходников убраны; поля плана, копирование и скачивание второго урока сохранены. Задание редактируется во вкладке «Уроки» в поле «Домашнее задание». Домашние задания отправляются в чат курса: ссылка есть в блоке задания каждого урока. Вопросы и обратную связь можно отправить через раскрывающуюся форму на странице. Вкладка «Вопросы» показывает переписку; ответы и прогресс находятся на вкладке «Участники». Ответ преподавателя виден участнику после обновления страницы. Уведомления о новых сообщениях не отправляются.

## Хранение и проверка

Материалы находятся в `app/Нейровизуал для учителя`. Связи с семью уроками и пятью дополнительными материалами заданы в `app/courses.py` по карте курса. Итоговые задания и чек-листы добавлены к каждому занятию.

Настройки, группы, ответы и переписка хранятся в SQLite в таблицах `course_*`. Иллюстрации вынесены из HTML без потери качества в `app/course-media` и выдаются только авторизованным покупателям и администратору. Обязательно загружайте эту папку вместе с кодом. Для старых исходников со встроенными изображениями сохранена поддержка кэша `course-assets` рядом с базой. Локальные MP4 исключены из Git и Docker: видео подключаются через VK. Самостоятельно исходники курса и кэш в публичную статику переносить не нужно.

Автоматические проверки: `python -m unittest test_courses test_shop_cart test_shop_sales test_payment_checks test_delivery_reliability` из каталога `app`. Они используют отдельные временные базы и имитацию платежей; реальные списания не создаются. Браузерная проверка охватывает переход с карты к уроку, сохранение ответов и прохождения, переписку, админку, раздел услуг и мобильную ширину.

Карта и уроки отображаются непосредственно как исходные HTML-страницы: без внутренних iframe, повторных заголовков и дублирующих карточек уроков. Чат доступен компактной кнопкой в шапке документа.

Рисованные листики созданы встроенным imagegen: `app/static/assets/course/painted-leaf.png`, промпт — `maintenance/course-leaf-prompt.txt`. Общие данные библиотеки промптов сворачиваются; внутри панели есть «Сбросить всё». Счётчик склоняет слово «промпт» по количеству. Панели цветового компаса белые и непрозрачные; декоративный рисунок внутри них отключён. Тёплые цвета CSS-подложек материалов заменены холодными без изменения цветов изображений и рабочих палитр компаса.

Для проверки VK используется адрес localhost: в браузерной проверке тот же плеер загружается на localhost, а во фрейме страницы с цифровым адресом 127.0.0.1 возвращает «Видео недоступно». Сервер продолжает слушать только локальный интерфейс. На опубликованном сайте доступность записи проверяется отдельно.

В первом уроке после предложенного инструмента размещена карусель из пяти авторских инфографик. Она становится видимой вместе с рекомендацией после выбора задачи. Кнопки листания, клавиши влево/вправо и увеличение позволяют читать картинки на компьютере и телефоне. Исходные PNG сохранены в `app/course-media`, выдаются через защищённый `/api/courses/asset` и не требуют папки Downloads.

Аудит перед публикацией и оставшиеся зоны риска: [COURSE_DEPLOY_AUDIT_2026-11-25.md](COURSE_DEPLOY_AUDIT_2026-11-25.md).

Для уменьшения исходников после добавления новых HTML со встроенными картинками: `python maintenance/extract-course-images.py`. Резервные копии создаются в игнорируемой папке `tmp/course-before-image-extraction`.

В «Экспериментах» все 52 изображения с примерами открываются крупно по нажатию или Enter/пробелу. В просмотре есть увеличение для мелких деталей, прокрутка и закрытие кнопкой «× Закрыть», по Escape или по фону.
