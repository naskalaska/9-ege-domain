ЛЕТНИЙ БАР — ИГРА-КВЕСТ ПО ДЕЕПРИЧАСТНОМУ ОБОРОТУ

1. Откройте файл index.html двойным щелчком.
2. Интернет для игры не нужен.
3. Чтобы добавить фоновую музыку, положите файл melody.mp3 в папку assets.
4. Не переименовывайте и не разъединяйте файлы и папку assets.
5. Прогресс сохраняется в браузере автоматически.
6. В первых четырёх локациях — по 5 заданий: найти, выделить,
   выписать и расставить запятые. В финальной локации — ещё 20 заданий.
7. Кнопка с карандашом включает рисование поверх задания. Доступны три
   цвета, настройка толщины, очистка рисунка и кнопка «Готово».

Сбросить прохождение можно кнопкой «Начать заново» на финальном экране
или очисткой данных сайта в браузере.
